# CP-012 — Honest stopping is part of useful discovery

Recorded: 2026-09-10. Owner clarification following the EXP-SIM-002 review.

Before: we described success as a shortlist or no match plus practical next steps.
Evidence: Eliot accepted the review recommendations, then explicitly emphasised
transparency about offering limitations and honesty when no next step is available.

Changed thinking: requiring an action at every endpoint can incentivise fabricated
or incompatible advice. A grounded, bounded explanation and an honest stopping
point can be sufficient. This is an accepted product standard, not measured
real-user trust. See [decision 0007](../../decisions/0007-honest-no-match.md).

The education contract and experiment review now record that qualification.
Original prompts, design snapshots and run reports preserve their earlier state.
Runtime repairs and targeted regression execution remain the next increment;
this documentation change does not claim changed Clara behavior or retest results.
