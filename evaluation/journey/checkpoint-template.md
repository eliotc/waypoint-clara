# CP-NNN — meaningful learning or decision

Recorded on: YYYY-MM-DD. Period covered: date or explicitly uncertain interval.
Provenance: contemporaneous / retrospective. Author/reviewer: name and role.
Predecessor: checkpoint link. Sources: decisions, experiment IDs, run IDs, code
revision if available, or identified conversation statement (without inventing IDs).

## Before
What did we believe or aim to establish? What assumptions and alternatives mattered?

## Evidence and limitations
What did we actually observe? Identify evidence kind and concrete references.
Distinguish absent evidence, data defects and application defects. State gaps in
retrospective reconstruction and unavailable artifacts.

## Changed thinking
What changed, stayed the same, or was contradicted? Why? Separate observations
from inference. If reversing an earlier interpretation, name it explicitly.

## Dispositions
Owner decision (quote or faithful paraphrase with source), AI recommendation,
implementation choice, and unresolved question should be labeled separately.
Link to a decision record for a material accepted choice; say if none was made.
Do not infer approval from acknowledgment or a successful automated check.

## Next and revisit trigger
What follows, and what evidence would make us reconsider? Link subsequent work
when available via a new checkpoint; preserve the original expectation here.
