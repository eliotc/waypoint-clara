# Finding / repair handoff

- Finding ID and status: proposed / reproduced / accepted / repaired / verified.
- Primary layer: application / domain evaluation / harness (core or target adapter).
- Component and current path:
- Evidence: run/scenario/turn or reproducible test; distinguish inspection risk.
- Contract violated and source of authority:
- Root-cause hypothesis and uncertainty:
- Proposed fix at the owning layer:
- Supporting changes in other layers:
- Verification: negative cases, positive controls, preserved baseline and scope.
- Evidence handling: regrade recorded output or rerun changed behaviour; why?
- Owner decision required: only for a new or changed product criterion; cite any
  existing authorization rather than requesting it again.
- Outcome and remaining limitations:

Do not equate a passing guard with a compliant model proposal, transport success
with semantic correctness, or a rubric change with improved agent behaviour.
