# Decision 0006: Test standalone discovery before integrated human handoff

Date: 2026-09-09. Owner: Eliot. Status: accepted direction; value/adoption remain
hypotheses to test. Source: owner agreement to the standalone discovery proposal,
request to use personas while actual user testing is unavailable, and request for
UI guidance about AI reliability and limitations.

Defer the proposed integrated handover-record increment from CP-009. Clara's
initial service should deliver useful discovery independently: clarified goals,
grounded options or an explained lack of a match, unresolved requirements and
practical next steps. A summary is for the student; it need not imply a transfer,
application, persistent save or communication with an institution.

Grounded human contact remains available when requested. This narrows the next
implementation priority; it does not excuse omissions, fabricated personal facts
or false transfer claims. It qualifies the handover emphasis in decision 0002's
rule 4 and supersedes CP-009's proposed next step, not its recorded evidence.

UI guidance should make the fictional demo status, exploratory purpose and
unverified eligibility apparent, with further explanation available. It can
support appropriate confidence but cannot eliminate overtrust or compensate for
contradictory confident advice. Keep uncertainty in responses and cards too.

Use synthetic personas to explore likely misunderstandings, useful next steps and
excessive dismissal as well as excessive trust. Label generated interpretations,
source assumptions and missing real-user evidence. Simulation is not a substitute
for evidence that people notice the UI or would adopt the product. No satisfaction
percentage or release gate is accepted from the initial pilot.

Revisit integrated handoff when it is necessary to complete the promised user
outcome or supported by partner workflow evidence. Revisit UI copy when actual
behavior/interpretation evidence reveals confusion. See
EXP-SIM-001 *(withheld)* and [CP-010](../journey/checkpoints/CP-010-standalone-discovery.md).
